# 라벨 카탈로그와 판별 규칙

SKILL.md의 표만으로 라벨 선택이 애매할 때 읽는 보충 자료. 라벨의 원본은 같은 폴더의 `labels.json`이고, `scripts/sync-labels.ps1`이 그 내용을 저장소에 반영한다.

## 유형 (이슈당 1개)

`data-commit`의 커밋 type과 1:1로 맞춘다. 이슈 라벨과 커밋 type이 같은 기준이어야 "이 이슈가 어떤 커밋으로 풀렸는지"가 읽힌다.

| 라벨 | 색 | 쓰는 경우 | 커밋 type |
|---|---|---|---|
| `기능` | `a2eeef` | 새 분석·지표·기능·스크립트 추가 | feat |
| `버그` | `d73a4a` | 오류·잘못된 집계/조인/필터 수정 | fix |
| `데이터` | `5319e7` | 원천·더미·참조 데이터 추가/갱신/삭제 | data |
| `분석` | `1d76db` | 탐색적 분석(EDA)·노트북·분석 결과 문서 | analysis |
| `시각화` | `e99695` | 차트·지도·대시보드·리포트 시각화 | viz |
| `파이프라인` | `d93f0b` | ETL·수집·스케줄·전처리 흐름 | pipeline |
| `모델` | `b4a7e5` | 피처·모델 학습/튜닝/평가 | model |
| `개선` | `bfdadc` | 결과가 바뀌지 않는 구조·성능 개선 | refactor, perf |
| `문서` | `0075ca` | README·데이터 사전·주석 | docs |
| `환경` | `ededed` | 의존성·환경·설정·잡무 | build, chore |

`기능`·`버그`·`문서`는 GitHub 기본 라벨(`enhancement`·`bug`·`documentation`)의 이름을 바꾼 것이다. 나머지 기본 라벨(`duplicate`, `question`, `wontfix` 등)은 그대로 두고, 이 스킬은 자동으로 달지 않는다.

### 애매할 때

| 상황 | 선택 | 이유 |
|---|---|---|
| 새 분석 스크립트 + 결과 표/문서 | `기능` | 재사용되는 스크립트가 산출물 |
| 일회성 탐색, 노트북으로 살펴보기 | `분석` | 결과가 코드가 아니라 발견 |
| 결과물이 그림 위주 | `시각화` | |
| 수치가 틀려서 고침 | `버그` | 결과가 달라짐 |
| 기준(필터·집계 단위)을 새로 추가 | `기능` | 오류가 아니라 요구 변경 |
| 함수 분리·속도 개선, 수치 동일 | `개선` | 결과 불변 |
| 더미 데이터 생성 스크립트 + 데이터 | `데이터` | 목적이 데이터 확보 |
| 데이터 검증 로직을 파이프라인에 추가 | `파이프라인` | |
| 스킬·`.gitignore`·린트 설정 | `환경` | |

여러 유형에 걸치면 **이슈를 나눌 수 있는지** 먼저 본다. 나눌 수 없으면 최종 산출물 기준으로 하나만 고른다.

## 주제 (이슈당 0~2개)

| 라벨 | 대응 scope |
|---|---|
| `주제: 버스` | `bus` — 특정 하위 도메인으로 좁힐 수 없을 때 |
| `주제: 노선` | `routes` |
| `주제: 하차` | `alighting` |
| `주제: 정류장` | `stops` |

- 색은 모두 `006b75`.
- 구체적인 주제가 있으면 `주제: 버스`는 붙이지 않는다 (모든 이슈에 붙으면 걸러 볼 가치가 없다).
- 3개 이상에 걸치면 `주제: 버스` 하나만 단다.
- 도메인과 무관한 작업(환경·문서)은 주제를 생략한다.
- **새 주제 추가**: 초안에서 사용자 승인을 받은 뒤 `labels.json`에 `{ "name": "주제: OO", "color": "006b75", "description": "... (scope: xx)" }`를 추가하고 `sync-labels.ps1`을 실행한다. 이 표와 `data-commit`의 scope 목록도 함께 맞춘다.

## 하지 말 것

- 유형 라벨 2개 이상, 상태 라벨 2개 이상 달기
- 영문 라벨 새로 만들기 (이 저장소 라벨은 모두 한글)
- `labels.json`을 거치지 않고 `gh label create`로 직접 만들기 — 카탈로그와 저장소가 어긋난다
- 기존 라벨 삭제 — 이미 달린 이슈에서 사라진다. 이름을 바꿔야 하면 `labels.json`의 `rename_from`을 쓴다
